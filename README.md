# SApixi Platform

SApixi is a platform designed to build, configure and deploy applications
to Kubernetes.

## Current stage

The current version contains the first static web interface used to validate:

- Docker image creation
- Nexus image publication
- Kubernetes deployment
- Kubernetes Service
- NGINX Ingress
- HAProxy routing
- Argo CD synchronization

## Planned components

- Web dashboard
- Backend API
- Real-time deployment events
- GitLab integration
- Nexus integration
- Kubernetes integration
- Argo CD integration
- Helm chart generation
- AI-assisted application analysis
